# Meme Me — Face Meme Matcher 🎭😆 

Meme me is fun, exciting application captures your expressions into memes! Don't just send or consume memes! Interact and make them your own!

😆 Meme Me uses AI to detect facial landmarks, analyzing  live webcam expressions and poses in real time, and then finds the closest iconic internet meme to match it.

### Getting Started with Meme Me!

 Install the necessary dependcies through

```
pip install -r requirements.txt
```

Ensure you're in the correct directory. 

```
cd backend
```

```
pw
```

Start the Meme Me app through

```
python app.py
```


### Dependcies / Tools

- HTMl/CSS/JS
- Faceapi.js
- Flask
